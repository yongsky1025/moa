고려해야될점
- 객체지향원칙 지켜가며 코드 구성
- 패키지 구조 짤때 복잡하지 않게
   (이유: 채팅 기능이 생각해야 될게 많지만 코드 자체는 짤 게 많이 없는걸로 알고 있음)
- 멋대로 만들지 말고 소스 텍스트 참고/고려해서 만들 것
- 팀원들과 머지할때 무조건 충돌이 나겠지만 충돌이 나도 간단하게 해결할수 있도록 코드 구성
- 나머지는 추후에 추가 할 것
2. 먼저 핵심적으로 구현해야될 기능
    - 채팅유형
    - 1:1 채팅기능
    - 모임 채팅기능
    - 메시지 기능
(이 기능을 중점으로 완벽 구현 후 추후 기능 추가 예정)

    - VSCode(java17 version)
    - DBeaver
    - springboot
    - postman
    - WebSocket(STOMP over SockJS)
    - Mysql
    - jpa
    - Socket.io cilent
(웹사이트는 나중에 팀원들과 구현 지금은 postman 안에 있는 WebSocket 기능을 이용하여 테스트 예정)
    - lombok
    - DTO(record문을 활용함)
